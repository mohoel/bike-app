# BikeApp-Icon – Ebenen für Icon Composer

Jede Variante liegt als transparente 1024×1024-SVGs vor, eine Datei pro Ebene.
Die Nummer im Dateinamen ist die Reihenfolge von hinten nach vorn.

## So geht's in Icon Composer
1. Neues Icon anlegen.
2. Die SVGs eines Ordners ins Ebenen-Panel ziehen, `1-…` ganz unten.
3. Den Hintergrund auf eine Vollfarbe setzen (siehe unten). Die Squircle-Maske legt Composer selbst darüber; nichts vorab abrunden.
4. Optional: die vorderste Ebene (Gabel/Rahmen) auf „Liquid Glass“ stellen und die Speichen-Ebene leicht transparent, so entsteht Tiefe.

| Variante | Hintergrund | Ebenen |
|---|---|---|
| A-Anschnitt | `#162033` | 1-Speed, 2-Rad, 3-Rahmen |
| B-Zonen-Felge | `#121A2B` | 1-Rad, 2-Zonen, 3-Gabel |
| C-Puls-Strecke | `#FF5A1F` | 1-Puls, 2-Rad, 3-Gabel |

Die Teile, die über den Rand ragen (Rahmen, Gabel, Reifen), sind absichtlich angeschnitten.
